Case study / Photography studio

Photography Studio Demo

A niche-specific client website for wedding, newborn, maternity, and family photography, built by reusing the Service Business Website Kit's shared CSS and JavaScript.

Open live demo ↗ View kit case study ↗
AudienceCouples, new parents, expecting mothers, families
RoleNiche positioning, content model, demo build
StackHTML shell, shared CSS/JS, JSON content
StatusReusable-kit demo with local inquiry capture
01Problem

Photography clients book emotion, trust, and timing before they compare features.

A studio website needs to show mood quickly, explain packages clearly, and capture the practical details that determine whether a session is viable: date, session type, location, people involved, and desired feeling.

02Solution

Reuse the service kit, then specialize the content for photography.

  • The page uses the same shared layout, CSS, and JavaScript as the Service Business Website Kit.
  • `data/site.json` changes the brand, hero, session packages, proof points, testimonials, gallery, and FAQ.
  • The form captures session inquiries locally with a photography-specific storage key.
  • The next backend step is to persist leads and review them from the existing Admin Console.
03Collections
01

Wedding Story: timeline planning, ceremony, portraits, reception, preview gallery, and final delivery.

02

Newborn & Baby: calm home or studio session with parent and sibling portraits.

03

Maternity Portraits: elegant studio or outdoor session with wardrobe and mood direction.

04Trade-offs

The current demo proves niche adaptation, not full studio operations.

The inquiry form stores local demo leads only. Before using this as a real business system, `P2-11` should add FastAPI lead persistence, Admin Console lead status updates, export/backup, and then optional calendar/payment integration.

05Commercial step

This becomes the first real niche offer for Robin's future photography studio direction.

The demo can be sold as a premium photography website first, then extended into booking workflow, lead follow-up, proposal templates, reminders, and client-gallery operations.
